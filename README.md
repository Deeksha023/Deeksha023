# Featured Projects

### AI Job Assistant

**AI-powered job recommendation platform**

Developed a full-stack AI-powered job recommendation platform using **FastAPI, React/TypeScript and PostgreSQL**.

**Key Features**
- RAG-based resume and semantic job search
- AI chat functionality
- Intelligent job matching
- JWT authentication
- CRUD operations for companies and job listings

**Tech Stack:** `FastAPI` `React` `TypeScript` `PostgreSQL` `RAG`

### Network Intrusion Detection System

**Machine Learning based Network Intrusion Detection**

Built a machine learning-based **Network Intrusion Detection System (NIDS)** using the **NSL-KDD dataset** to classify network traffic as normal or malicious.

**Key Features**
- Network traffic classification
- Data preprocessing
- Feature engineering
- Random Forest classification
- Model evaluation and analysis

**Tech Stack:** `Python` `Machine Learning` `Random Forest` `NSL-KDD` `Scikit-learn`
